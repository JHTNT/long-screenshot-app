# 長截圖拼接規格

## 1. 文件目的

本文件集中定義第一版自動拼接器的輸入、輸出、比對流程、可信度與降級條件。目標是讓相同輸入得到可重現結果，並讓測試能判斷接縫是否正確。

本文件維護長期行為契約，不固定可直接由程式碼讀到的取樣步距與校準常數。現行值集中在 `StitchMatcher`，必須由測試資料校準；本文的品質門檻仍是驗收目標，不代表已有 fixture 證明達成。

第一版假設畫面只發生垂直捲動。圖片不旋轉、不縮放、不做水平校正；不符合假設時轉入手動處理或要求重新擷取。

## 2. 設計原則

1. **錯誤拒絕優先：** 寧可標示低信心，也不可高信心接受錯誤接縫。
2. **原圖不變：** 灰階、縮圖與梯度只用於搜尋；合成永遠取自來源 PNG。
3. **相鄰處理：** 只比對擷取順序相鄰的圖片。
4. **由內容決定：** 系統區域資訊是提示，不是固定裁切答案。
5. **結果可解釋：** 每個接縫都回傳位移、分數、可信度及拒絕原因。
6. **先用簡單方法：** 同一螢幕的截圖沒有縮放或透視，先使用像素與梯度相關性；測試證明不足才加入特徵點套件。

## 3. 名詞

| 名詞 | 定義 |
| --- | --- |
| 來源圖片 | MediaProjection 擷取後保存的原始 PNG |
| 前圖 A | 相鄰圖片中較早擷取的一張 |
| 後圖 B | 相鄰圖片中較晚擷取的一張 |
| 內容區 | 排除可信系統列提示後，用於捲動內容比對的區域 |
| 位移 `d` | 使用者由 A 捲動到 B 的垂直像素距離 |
| 重疊高度 | A 與 B 共同內容的高度 |
| 接縫 | 合成時由 A 切換到 B 新內容的位置 |
| 候選 | 一個可能的位移與其比對分數 |
| 高信心 | 可自動採用的唯一可靠候選 |
| 低信心 | 必須由使用者確認或調整的結果 |

## 4. 輸入

每張來源圖片至少包含：

- 來源檔案。
- 擷取順序。
- 原始寬度與高度。
- 擷取時的螢幕方向（規劃；目前由 Activity 固定直向與圖片尺寸間接限制）。
- 投影模式（整螢幕或單一應用程式），據此判斷是否含系統列（規劃；目前尚未記錄）。
- 當時可取得的狀態列、導覽列或安全區提示；目前工作階段只保存共用的頂端與底端 inset。

輸入前置檢查：

- 圖片可完整解碼。
- 寬度與高度在同一工作階段一致；方向欄位驗證仍待投影中斷恢復流程補齊。
- 寬高大於零。
- 至少有一張有效圖片。

任何圖片無法解碼時，停止自動拼接並保留所有仍可讀來源；不得跳過中間圖片後繼續猜測順序。

## 5. 輸出

每一對相鄰圖片輸出一筆接縫提案：

| 欄位 | 說明 |
| --- | --- |
| 前圖與後圖序號 | 接縫所屬圖片 |
| 垂直位移 | B 相對於 A 的捲動距離 |
| 重疊高度 | 共同內容範圍 |
| 前圖底部裁切提示 | 自動偵測到的固定底部區域高度，作為初始手動計畫的裁切值 |
| 最佳分數 | 最佳候選的比對結果 |
| 次佳差距 | 最佳與其他合理候選的分離程度 |
| 可信度 | 高或低 |
| 原因 | 通過、低紋理、結果歧義、無重疊、動態差異等 |

單張工作階段不產生接縫提案，直接以原圖進入輸出預覽。

## 6. 處理流程

### 6.1 預處理

每次只讀取相鄰兩張來源：

1. 解碼相鄰來源並確認尺寸。
2. 建立比對專用灰階資料。
3. 評分時依圖片尺寸抽樣亮度與局部梯度，降低純色背景對分數的影響。
4. 套用可取得的頂端、底端 inset 或使用者指定的共同內容區域。

不得把縮圖、灰階或梯度影像寫回來源檔。

### 6.2 內容區

單一應用程式模式的來源不含系統列，內容區即整張圖片；本節其餘規則僅適用整螢幕模式。

系統提供的頂端與底端區域可先排除於搜尋範圍，但需遵守：

- 只排除合理且位於圖片邊界的區域。
- 資訊缺失或明顯超出圖片時視為未知。
- 系統區域只影響比對，不代表成品一定照同一高度裁切。
- 第一張最上方與最後一張最下方預設保留。
- 中間圖片只有在內容配對支持相同切點時，才移除系統區域。

如果無法取得可靠提示，仍可在原圖上搜尋；需降低固定頂端與底端圖樣的權重，避免狀態列本身成為錯誤的零位移配對。

### 6.3 候選位移搜尋

對每組 A、B：

1. 先檢查是否為完全或近乎完全重複的連續截圖。
2. 搜尋向下捲動的正位移；第一版不自動接受反向捲動。
3. 預設搜尋範圍為內容區高度的 5% 到 95%。
4. 在縮小影像上做粗略搜尋，再回到原始解析度附近細調。
5. 每個候選比較 A 的下段與 B 的上段共同範圍。
6. 分別計算左、中、右三個直向區帶，再合併結果，避免單一浮動元件支配整張圖。
7. 同時考慮亮度差與梯度差；大面積純色不計為充分證據。

若使用者捲動後共同內容少於搜尋下限，預期結果是低信心「重疊不足」，不是任意選擇最接近候選。

### 6.4 細部比對

粗略最佳候選附近需以原始解析度重新比較：

- 位移細調至少涵蓋粗略結果前後 8 個原圖像素。
- 三個區帶的最佳位移差距不得超過 2 px。
- 可忽略未超過約一半重疊範圍的動態橫帶，但仍需有足夠靜態內容支持同一位移。
- 若不同位移得到近似分數，例如規律清單、棋盤或大片重複線條，標記為歧義。

### 6.5 可信度規則

比對分數正規化為 0 到 1，1 代表完全相同。只有最佳相似度、有效紋理、候選唯一性、至少兩個區帶的相似度、區帶位移一致性及最低重疊量全部通過，才可標為高信心；任一條件不通過即回傳低信心與具體原因。

校準常數集中在 `StitchMatcher`，不做成使用者設定，也不重複抄入長期文件。調整常數時必須同步新增或更新會防止回歸的測試；建立標準 fixture 後，再以[測試計畫](05-test-plan.md)的精度門檻決定是否可接受。

### 6.6 特殊情況

#### 完全重複

若 A、B 在排除合理系統區域後近乎完全相同：

- 將 B 標記為重複圖片。
- 預覽中提示使用者。
- 預設不把 B 加入成品。
- 不視為拼接錯誤。
- 使用者可在預覽將 B 改為保留；保留後該接縫視為低信心接縫進入手動修正，且與 B 相鄰的接縫需重新評估。

#### 無重疊

若所有候選都未通過最低相似度：

- 回傳低信心「找不到重疊」。
- 不自動建立接縫。
- 交由手動上下移動與裁切。

#### 反向或回捲

若負位移明顯比正位移合理：

- 回傳低信心「可能向上捲動」。
- 第一版不自動接受。

#### 低紋理

若畫面主要為純色、漸層或空白：

- 不因低像素差而判定高信心。
- 回傳低信心「可辨識內容不足」。

#### 固定元件與動態內容

若三個區帶無法對同一位移達成一致，或動態內容佔據大部分重疊範圍：

- 回傳低信心「畫面內容不一致」。
- 不嘗試辨識影片或動畫；若像素差異形成橫帶，接縫移到最近的穩定列，使動態區只取自其中一張來源。

## 7. 系統列與合成規則

合成結果由上到下遵守：

1. 第一張圖片的頂端系統區域保留一次。
2. 第一張底端只有在它不是捲動內容且接縫結果支持時才移除。
3. 後續圖片只加入已配對重疊範圍之後的新內容。
4. 中間圖片的頂端與底端系統區域不重複加入。
5. 最後一張底端系統區域保留一次。
6. 系統區域資訊與內容比對衝突時，標記低信心，不自動裁切可能是真實內容的部分。

單一應用程式模式的來源沒有系統區域，上述關於系統區域的規則自然不適用，其餘規則不變。

自動合成使用整數像素邊界，不做混合、羽化或插值，避免文字模糊。

## 8. 手動調整整合

- 自動接縫提案是手動編輯器的初始值。
- 高信心接縫可直接採用，但使用者仍可進入查看。
- 低信心接縫必須由使用者確認。
- 手動位移與上下裁切以原始圖片座標保存。
- 變更某張圖片裁切後，需重新檢查與它相鄰的兩個接縫。
- 手動結果只改變合成參數，不覆寫來源 PNG。

## 9. 成品幾何

產生成品前先計算，不先配置 Bitmap：

1. 套用每張圖片的頂端與底端裁切。
2. 套用每個已確認接縫的重疊移除。
3. 驗證每張圖片仍有正高度。
4. 驗證每個接縫順序為向下且沒有負成品高度。
5. 成品寬度等於來源寬度。
6. 成品高度等於所有實際保留區段高度總和。
7. 使用長整數計算尺寸，轉成平台整數前檢查溢位。

任一驗證失敗都回到手動修正，不配置成品。

## 10. 升級條件

符合以下任一條件，才評估 OpenCV、特徵點或更複雜模型：

- 高信心接縫精度未達 99%，且錯誤不是測試資料或門檻問題。
- 支援範圍內的自動完成率未達 90%。
- 多數失敗案例確實需要處理小幅水平位移或非像素一致變化。
- 新方案有可重現測試，並證明改善大於套件大小、建置與維護成本。

升級不得改變低信心時轉手動的安全原則。
